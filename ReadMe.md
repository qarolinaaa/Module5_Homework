# TaskManager — ASP.NET Core Web API и клиентское приложение

## Описание проекта

Проект выполнен в рамках самостоятельной работы по дисциплине **CSE5032 «Разработка веб-сервисов»**, Модуль 05.

Проект состоит из двух ASP.NET Core приложений:

* **TaskManagerApi** — Web API для управления задачами;
* **TaskManagerClient** — клиентское ASP.NET Core приложение, взаимодействующее с Web API с помощью `HttpClient` и `IHttpClientFactory`.

Клиентское приложение позволяет получать список задач, просматривать отдельную задачу, добавлять, редактировать и удалять задачи.

## Модель TaskItem

Модель задачи содержит следующие основные поля:

* `Id` — идентификатор задачи;
* `Title` — название задачи;
* `Description` — описание задачи;
* `IsCompleted` — статус выполнения задачи.

## Web API

API предоставляет HTTP-методы для работы с задачами:

| Метод  | Endpoint          | Назначение                    |
| ------ | ----------------- | ----------------------------- |
| GET    | `/api/tasks`      | Получение списка всех задач   |
| GET    | `/api/tasks/{id}` | Получение одной задачи по ID  |
| POST   | `/api/tasks`      | Добавление новой задачи       |
| PUT    | `/api/tasks/{id}` | Изменение существующей задачи |
| DELETE | `/api/tasks/{id}` | Удаление задачи               |

### Адрес Web API

При локальном запуске API используется адрес:

```text
https://localhost:XXXX
```

> Вместо `XXXX` необходимо указать фактический порт, который используется проектом `TaskManagerApi`.

Например:

```text
https://localhost:7168
```

## Клиентское приложение

`TaskManagerClient` представляет собой ASP.NET Core приложение, которое отправляет HTTP-запросы к `TaskManagerApi`.

На странице списка задач отображаются:

* ID задачи;
* название;
* статус;
* действия «Изменить» и «Удалить».

Также реализована кнопка **«Добавить задачу»**.

## Реализованные операции

### 1. Получение списка задач

Клиент отправляет GET-запрос:

```http
GET /api/tasks
```

Полученные задачи отображаются на странице.

### 2. Получение одной задачи

Для получения задачи по идентификатору используется:

```http
GET /api/tasks/{id}
```

Например:

```http
GET /api/tasks/5
```

### 3. Добавление задачи

Для создания новой задачи используется POST:

```http
POST /api/tasks
```

Данные задачи передаются в формате JSON.

### 4. Изменение задачи

Для изменения существующей задачи используется PUT:

```http
PUT /api/tasks/{id}
```

Пользователь может изменить:

* название;
* описание;
* статус выполнения.

### 5. Удаление задачи

Для удаления используется:

```http
DELETE /api/tasks/{id}
```

Перед удалением приложение запрашивает подтверждение пользователя.

## Использование HttpClient

Для взаимодействия с Web API используется `IHttpClientFactory`.

В приложении зарегистрирован именованный `HttpClient` с помощью:

```csharp
builder.Services.AddHttpClient("TaskApi", client =>
{
    client.BaseAddress = new Uri("https://localhost:XXXX");
});
```

`HttpClient` получается через `IHttpClientFactory`, а не создаётся заново перед каждым запросом.

Пример получения клиента:

```csharp
public class TaskService
{
    private readonly IHttpClientFactory _httpClientFactory;

    public TaskService(IHttpClientFactory httpClientFactory)
    {
        _httpClientFactory = httpClientFactory;
    }
}
```

После этого клиент используется для выполнения HTTP-запросов к Web API.

## Обработка ответов API

Клиентское приложение проверяет результаты выполнения HTTP-запросов.

Обрабатываются следующие основные HTTP-статусы:

* **200 OK** — запрос успешно выполнен;
* **201 Created** — ресурс успешно создан;
* **400 Bad Request** — некорректные данные запроса;
* **404 Not Found** — задача не найдена;
* **500 Internal Server Error** — внутренняя ошибка сервера.

При возникновении ошибки пользователю выводится понятное сообщение, а приложение не должно аварийно завершаться.

## Запуск проекта

### Шаг 1. Запуск Web API

Сначала необходимо запустить проект:

```text
TaskManagerApi
```

После запуска необходимо проверить адрес и порт Web API.

### Шаг 2. Настройка клиента

В `TaskManagerClient` необходимо указать соответствующий адрес Web API в настройках `HttpClient`.

Например:

```text
https://localhost:7168
```

### Шаг 3. Запуск клиентского приложения

После запуска `TaskManagerClient` в браузере открывается страница со списком задач.

Через интерфейс можно:

* просматривать задачи;
* получать отдельную задачу;
* добавлять задачи;
* редактировать задачи;
* удалять задачи.
